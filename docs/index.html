Honest limitations

Some request bodies (promotions, transactions, disputes, billing, custom objects, business rules) are free-form JSON; the AI should check the official reference. Payment provider and shipping carrier endpoints are for partner apps. Not on npm yet: install from GitHub.

Frequently asked questions

What is a Tiendanube MCP server?

It is a small program that lets an AI assistant call the Tiendanube API as tools. You describe what you want and the AI chooses the operations, such as listing products, updating stock or creating coupons.

Does it work with Nuvemshop in Brazil?

Yes. Set TIENDANUBE_API_DOMAIN to https://api.nuvemshop.com.br.

Do I need to know how to code?

No. Paste the one-line install prompt into your AI agent and answer its questions. The credentials guide explains how to get your Store ID and access token.

Can the AI delete my products by mistake?

Not in read-only mode. In read-write mode, delete and cancel tools are flagged destructive so well-behaved clients ask for confirmation. Back up your catalog before bulk operations.

How much does it cost?

The server is free and MIT licensed. You only pay for the AI service you already use. Tiendanube API access depends on your plan.

Which AI tools does it work with?

Claude Code, Claude Desktop, OpenAI Codex, OpenCode, Gemini CLI, Cursor, VS Code with Copilot, Windsurf and any client that supports MCP over stdio or HTTP.
