Modo solo lectura opcional

Un único ajuste elimina todas las herramientas de escritura si querés más seguridad.

Anotaciones honestas

Cada herramienta declara si es de lectura, destructiva o idempotente para que el cliente pida confirmación antes de borrar.

Limitaciones, con honestidad

Algunos cuerpos de request (promociones, transacciones, disputas, billing, custom objects, reglas de negocio) son JSON libre; la IA debe consultar la referencia oficial. Los endpoints de proveedores de pago y transportistas son para apps de partners. Aún no está en npm: se instala desde GitHub.

Preguntas frecuentes

¿Qué es un servidor MCP de Tiendanube?

Es un programa pequeño que permite a un asistente de IA usar la API de Tiendanube como herramientas. Describís lo que querés y la IA elige las operaciones: listar productos, actualizar stock, crear cupones.

¿Funciona con Nuvemshop en Brasil?

Sí. Configurá TIENDANUBE_API_DOMAIN con https://api.nuvemshop.com.br.

¿Necesito saber programar?

No. Pegá el prompt de instalación en tu agente de IA; él maneja las claves y la configuración por vos. La guía de credenciales explica cómo obtener el ID de tienda y el access token.

¿Puede la IA borrar mis productos por error?

Las herramientas pueden borrar y están marcadas como destructivas para que los clientes bien diseñados pidan confirmación, y las reglas para agentes le piden a la IA avisar antes de cambios masivos. Podés pasar a solo lectura cuando quieras. Hacé un backup del catálogo antes de operaciones masivas.

¿Cuánto cuesta?

El servidor es gratis y con licencia MIT. Solo pagás el servicio de IA que ya uses. El acceso a la API de Tiendanube depende de tu plan.

¿Con qué herramientas de IA funciona?

Claude Code, Claude Desktop, OpenAI Codex, Gemini CLI, Cursor, Google Antigravity, VS Code con Copilot, OpenCode, Windsurf, Cline y cualquier cliente que soporte MCP por stdio o HTTP.
