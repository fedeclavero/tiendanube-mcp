## Workflows and guidance

- `tiendanube_start_here` — CALL THIS FIRST. Map of tasks to tools, golden rules and recipes for this store.
- `tiendanube_find_tool` — Describe what you want to do in plain language (Spanish or English) and get the matching tools and recipes.
- `tiendanube_get_recipe` — Step-by-step recipe (exact tool names and arguments) for a common job such as combos, price changes or stock.
- `tiendanube_doctor` — Diagnose credentials, connection and missing permissions, with the exact next steps to fix them.
- `tiendanube_api_request` — Call any Tiendanube API route that has no dedicated tool (last resort before asking the user).
- `tiendanube_create_combo` — Create a combo/pack product from products already in the store, with price, stock and images (generated files supported).
- `tiendanube_product_image_add_from_file` — Upload an image file from this computer (e.g. one you generated) to a product.
